## ⚡ Quick Start (CLI)

Add any component directly into your React, Next.js, or Vite project with our native CLI:

```bash
# Add 3D Wireframe Vector Orbit Globe
npx atronix add orbit-globe

# Add Suspended Volumetric Pendant Lamp
npx atronix add pendant-lamp

# Add Hydrodynamic Fluid Metaball Button
npx atronix add liquid-mitosis

# Add Acoustic Swirling Smoke Nebula
npx atronix add aero-core
```

### List All Available Components

```bash
npx atronix list
```
